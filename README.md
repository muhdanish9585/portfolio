---

## Interactive dashboards

| Project | What it shows |
|---|---|
| [Luxury Hospitality Pest Intelligence](dashboards/luxury-hospitality.html) | Quarterly bait consumption, fly catches, complaint log, pest-type mix and month heatmap for a luxury hotel, with an executive presentation deck. |
| [Multi-Building Rodent Monitoring](dashboards/manufacturing-multibuilding.html) | TRBS & glue-board monitoring across four manufacturing buildings; per-building trend, heatmap and Q1 vs Q2 risk comparison. |
| [Multi-Outlet F&B Pest Dashboard](dashboards/hospitality-fb.html) | Incident analysis across 7 F&B locations: pest-type mix, location hotspots, monthly heatmap and period comparison. |
| [F&B Manufacturing Pest Dashboard](dashboards/malindo-fb.html) | Rat, ant and insect-light-trap monitoring: bait trend, fly composition, ant presence matrix and quarterly read-out. |
| [QA Glue-Board Catch Analysis](dashboards/qa-glue-board.html) | QA case-file for insect identification on an ILT glue board: annotated evidence, confidence scoring, catch composition and recommended actions. |

Each dashboard supports:
- **Full-screen dark / light theme**
- **Presentation deck** mode (press `P`)
- **Period toggles**, interactive **heatmaps** and tooltips
- **Print / Save-as-PDF** layout (press the Print button)

## Tech
